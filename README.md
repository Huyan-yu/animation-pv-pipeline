# 动画 PV 人物替换管线（Character Replacement Pipeline）

从一段新番宣传 PV 中截取若干片段，用标准日式人设图（character sheet）的人物替换原角色，
输出替换后的视频。管线设计以**可复用、稳定、可评估**为第一目标。

## 管线总览（5 阶段）

```
┌─────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌─────────────┐
│ 1. 选取     │   │ 2. 参考图    │   │ 3. 帧级替换  │   │ 4. 时序稳定  │   │ 5. 成片合成  │
│ 片段 + 关键帧│──▶│ 人设图解析  │──▶│ 图像/视频生成 │──▶│ 平滑/补间   │──▶│ 音画对齐     │
└─────────────┘   └──────────────┘   └──────────────┘   └──────────────┘   └─────────────┘
```

| 阶段 | 输入 | 输出 | 关键设计 |
|---|---|---|---|
| 1 选取 | 完整 PV | 片段 + 关键帧 | 只选"单人、静态、背景简单"的镜头，保证可复现 |
| 2 参考图 | 标准人设图 | 结构化角色描述（立绘 + 设定文本） | 人设图拆成"特征向量 + 文本锚点"，统一喂给生成模型 |
| 3 帧级替换 | 关键帧 + 角色描述 | 替换后关键帧 | 图像生成模型，prompt 由阶段 2 的描述驱动 |
| 4 时序稳定 | 替换前后帧序列 | 平滑后的序列 | 光流插值 / 帧间一致性，消除闪烁 |
| 5 成片合成 | 平滑序列 + 原音轨 | 最终视频 | 帧率对齐、音频重采样 |

**评估贯穿全程**：每个阶段有独立的量化指标（见下方），最终成片用统一的 75/90 评分制打分。

## 目录结构

```
config/     片段选取配置、人设图解析配置
scripts/    各阶段脚本 + 评估脚本
clips/      选取的片段（原始）
frames/     关键帧（原始 + 替换后）
assets/     人设图素材
outputs/    各阶段产物 + 最终视频
docs/       管线设计、评估方案、失败案例
```

## 运行

```bash
# 0. 环境
pip install -r requirements.txt
ffmpeg -version   # 需系统装好 ffmpeg

# 1. 选取片段（从 config 指定的 PV 路径截取）
python scripts/01_select_clips.py

# 2. 解析人设图 → 角色描述
python scripts/02_parse_reference.py

# 3. 关键帧替换（图像生成；无 key 时走 mock）
python scripts/03_replace_frames.py

# 4. 时序稳定（光流插值）
python scripts/04_stabilize.py

# 5. 合成最终视频
python scripts/05_compose.py

# 评估
python scripts/evaluate.py
```

## 可复用性设计（题目核心）

- **同一套 config 驱动所有片段**：片段 A、B 用完全相同的参数，不特调。
- **阶段解耦**：每阶段输入/输出都是标准格式（帧 + JSON 描述），可单独重跑。
- **评估同口径**：片段 A/B 用同一套指标 + 同一套评分制，方便横向对比稳定性。
